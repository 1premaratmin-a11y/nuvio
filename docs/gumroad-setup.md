# Nuvio — Gumroad Setup Guide

## Why Gumroad?
- Free to start (no monthly fee)
- Handles sales tax/VAT globally
- Takes 10% + 30¢ per sale
- Buyers can pay with credit card, PayPal, Apple Pay, Google Pay
- Built-in refund handling
- You get paid via bank deposit or PayPal

## Step-by-Step Setup

### 1. Create a Gumroad Account
1. Go to https://gumroad.com/signup
2. Sign up with your email
3. Verify your email
4. Set up your profile:
   - Name: Nuvio
   - Profile URL: nuvio (or nuvio-studio if taken)
   - Bio: "Websites that convert. Built fast, built right."

### 2. Set Up Payment Receiving
1. Go to Settings > Payments
2. Connect your bank account or PayPal
3. Set your payout frequency (weekly, monthly, or threshold-based)

### 3. Create Your First Product (Custom Website)
1. Go to https://app.gumroad.com/products
2. Click "New Product"
3. Set up as follows:
   - Name: "Custom Website — Starter ($499)"
   - Price: $499
   - Description: "A 1-page custom website built to your specifications. Mobile responsive, SEO-ready, contact form included. 5-day delivery."
   - Product type: Digital product (service)
   - Checkout settings: Enable "Pay what you want" = NO
   
4. Repeat for:
   - "Custom Website — Professional ($1,499)"
   - "Custom Website — Enterprise (Custom Quote)" — set as "Contact for price"

### 4. Create a Product for Each Pricing Tier

**Starter — $499:**
- Name: Nuvio Starter Website
- Price: $499
- Description: 1-page custom website, mobile responsive, contact form, basic SEO, 5-day delivery, 1 revision round
- Content: Include a PDF intake form (see client-onboarding folder)

**Professional — $1,499:**
- Name: Nuvio Professional Website
- Price: $1,499
- Description: Up to 5 pages, custom design, animations, advanced SEO, analytics, 7-day delivery, 3 revisions, 30-day support
- Content: Include intake form PDF

**Enterprise — Custom:**
- Name: Nuvio Enterprise Website
- Price: Set to "Pay what you want" with minimum $3,000, OR use a custom checkout
- Description: Unlimited pages, e-commerce, API integrations, CMS, priority delivery, unlimited revisions, ongoing support

### 5. Customize Your Gumroad Storefront
1. Go to Settings > Appearance
2. Set:
   - Header: "Nuvio"
   - Tagline: "Websites that convert. Built fast, built right."
   - Color: #7c3aed (match your brand)
   - Add a logo (create one at https://canva.com or use a simple SVG)

### 6. Get Your Store URL
- Your store will be at: https://nuvio.gumroad.com (or whatever you chose)
- Each product gets its own checkout link like: https://nuvio.gumroad.com/l/starter-website

### 7. Connect Gumroad to Your Nuvio Site
Update the "Get Started" buttons on your Nuvio site to link to your Gumroad product pages.
Replace the `contact.html` links on pricing cards with your Gumroad checkout links.

### 8. Set Up Email Automation (Optional)
Gumroad can automatically:
- Send a welcome email after purchase
- Send a follow-up email asking for project details
- Send a review request after delivery
- Use Gumroad's "Workflows" feature for this

### 9. Tax Settings
1. Go to Settings > Taxes
2. Gumroad handles this automatically — they collect and remit sales tax/VAT
3. You don't need to do anything extra — this is handled for you

## Payment Flow
1. Client visits your Nuvio site
2. Client clicks "Get Started" on a pricing tier
3. Client is redirected to Gumroad checkout
4. Client pays via credit card / PayPal / Apple Pay
5. Gumroad sends you notification + buyer email
6. You (or Nuvio) contact the client to start the project
7. You build the site, deliver it, and deploy it
8. Done!

## Fees Breakdown
- $499 sale → Gumroad takes ~$52.90 → You keep ~$446.10
- $1,499 sale → Gumroad takes ~$152.90 → You keep ~$1,346.10
- Custom pricing → 10% + 30¢ per sale

## Tips
- Use Gumroad's "Upsells" to offer add-ons (extra pages, SEO package, maintenance)
- Use "Offer codes" for discounts (e.g., 10% off for first-time clients)
- Enable "Pre-order" if you want to collect interest before the project starts
- Gumroad sends payouts to your bank/PayPal automatically
