# Nuvio — Modern Web Studio

Websites that convert. Built fast, built right.

Nuvio is a web studio that builds and sells custom websites. We use beautiful, production-ready templates as starting points and customize them per client.

## Structure

```
nuvio/
├── studio-site/          # Main Nuvio landing page (sells to clients)
│   ├── index.html
│   ├── about.html
│   ├── pricing.html
│   ├── contact.html
│   ├── 404.html
│   ├── css/style.css
│   └── js/main.js
├── templates/            # Reusable website templates
│   ├── saas-landing/      # SaaS product landing page
│   ├── portfolio/         # Creative portfolio site
│   └── restaurant/        # Restaurant website
├── assets/               # Shared assets
│   ├── css/
│   └── js/
└── README.md
```

- Pure HTML/CSS/JS — no frameworks, no build step
- GitHub Pages for free hosting
- Gumroad for payment processing
- Custom domain when client needs one
